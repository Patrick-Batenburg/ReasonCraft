# Dutch glossary

The Dutch interface (`app/reasoncraft/i18n/nl.ftl`) uses informal "je" and these fixed argument terms (ruling J3): bewering (claim), reden (reason), bezwaar (objection), weerlegging (rebuttal), medepremisse (co-premise), premisse (premise) and bron (source).
The table lists the other term choices (ruling S6-T4-2). They are open to review: change a term in `nl.ftl`, and check that the ribbon still fits (`ribbon_fits_in_dutch_at_1280`).
