# ReasonCraft user guide

ReasonCraft maps an argument: a claim at the top, the reasons for it and the objections against it below, each with the sources that back it up.
This guide is a short tour. The full help is built into the app (the Help tab of the Text panel, or F1) and works offline; its pages are linked below.

## First steps

1. Start ReasonCraft. File → New offers a blank map, four templates (Blank reasoning map, Blank grouping map, Essay plan, Peer review) and two example maps (a reasoning example and a grouping example). Open the reasoning example to see a finished map.
2. Type your claim into the selected box.
3. Press Tab to add a reason and Shift+Tab to add an objection. Ctrl+Enter adds a co-premise (Cmd+Enter on a Mac).
4. Add sources from the Home ribbon, the "+" button on a box, or the Building panel on the left.
5. Rate the map on the Evaluate tab: accept or reject claims, rate cards strong, weak or nil, and rate sources.
6. Open the Text panel on the right for the Outline, the Essay, the Check hints, your Snippets and the Help.
7. Save with Ctrl+S. Maps are `.rcraft` files. Recent maps are listed on the File page.

See [Getting started](../app/reasoncraft/help/en/getting-started.md).

## Languages

- **The interface** is in English or Dutch. It follows your computer's language until you choose one in View → Language or File → Settings, and it changes at once.
- **Each map** has its own language (File → Document). It decides the words drawn on the map (rating labels, source names), the linking words in the Outline and Essay, the spelling dictionary, the checks and the exports. A Dutch map stays Dutch when the interface is English, and the other way round.

The Dutch term choices are listed in [glossary-nl.md](glossary-nl.md).

## Settings

File → Settings holds the theme (light, dark or the system's, which is where it starts), the interface size (80 % to 200 %), the interface language, the language of new maps, your name for comments, autosave, spellcheck and the checks.
**Reset to defaults** puts every setting back as at the first start, but keeps your recent maps and your personal dictionary.
