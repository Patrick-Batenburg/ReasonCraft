# Files and recovery

## Saving and opening

- A map is saved as one `.rcraft` file. It holds the map, its images, the snippets and the essay.
- File > **Save** (Ctrl+S) saves the map; the first time, it asks where. **Save As** (Ctrl+Shift+S) saves a copy under a new name.
- File > **Open** (Ctrl+O) opens a map in a new tab. File > **New** (Ctrl+N) starts an empty map.
- Each open map has its own tab above the ribbon. Closing a tab, or the window, with unsaved changes asks whether to save them first.
- File > **Document** holds the title, the author and the language of the open map.

Files from older versions of ReasonCraft open unchanged. A file made with a newer version says so and asks you to update ReasonCraft.

## Autosave and recovery

While you work, ReasonCraft keeps a copy of every map with unsaved changes in a recovery folder: every 45 seconds by default. Your own files are only written when you save.

If ReasonCraft does not close normally, for example after a crash or a power cut, the next start offers to bring those maps back:

- **Restore all** opens them, marked "(recovered)", with their unsaved changes.
- **Discard all** throws the copies away.
- **Decide later** keeps them for the next start.

If the original file changed in the meantime, you are asked before it is replaced.

File > Settings sets how often autosave runs: from 30 to 600 seconds, or off.

## Settings

File > **Settings** holds your own preferences: the interface language and size, your name for comments, the theme, the language of new maps, spellcheck, autosave and the checks. **Reset to defaults** puts them all back as at the first start, except your personal dictionary.
