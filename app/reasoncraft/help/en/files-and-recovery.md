# Files and recovery

## Saving and opening

- A map is saved as one `.rcraft` file. It holds the map, its images, the snippets and the essay.
- File > **Save** (Ctrl+S) saves the map; the first time, it asks where. **Save As** (Ctrl+Shift+S) saves the map under a new name; from then on you work in that file.
- The file is written in the background, so you can keep working; the status bar shows **Saving…** meanwhile. What you change while it is written is not in the file: the map stays marked as unsaved until you save again.
- File > **Open** (Ctrl+O) opens a map in a new tab. File > **Recent** lists the last ten maps you opened or saved; click one to open it again.
- File > **New** offers a blank map, templates to start from and the example maps. Each opens in a new tab, as a map that has not been saved yet. Ctrl+N starts an empty map at once.
- Each open map has its own tab above the ribbon. Closing a tab, or the window, with unsaved changes asks whether to save them first.
- With many maps open, the tabs get narrower; when they no longer fit, the row shows the tabs around the one you are in, and the **▾** button at its end lists all open maps. Ctrl+Tab and Ctrl+Shift+Tab switch to the next or previous map, Ctrl+W closes the one you are in; Search commands has them too, as **Next tab**, **Previous tab** and **Close tab**.
- File > **Document** holds the title, the author and the language of the open map.

Files from older versions of ReasonCraft open unchanged. A file made with a newer version says so and asks you to update ReasonCraft.

## Autosave and recovery

While you work, ReasonCraft keeps a copy of every map with unsaved changes in a recovery folder: every 45 seconds by default. Your own files are only written when you save.

If ReasonCraft does not close normally, for example after a crash or a power cut, the next start offers to bring those maps back:

- **Restore all** opens them, marked "(recovered)", with their unsaved changes.
- **Discard all** throws the copies away.
- **Decide later** keeps them for the next start.

If the original file changed in the meantime, you are asked before it is replaced.

File > Settings sets how often autosave runs: from 30 to 600 seconds, or off.

## Settings

File > **Settings** holds your own preferences: the interface language and size, your name for comments, the theme, the language of new maps, spellcheck, autosave and the checks. **Reset to defaults** puts them all back as at the first start, except your personal dictionary and the list of recent maps.
