# Languages and spelling

ReasonCraft keeps two languages apart: the language of the **interface** (menus, buttons and this help) and the language of each **document** (the map you write).

## The interface language

View > **Language** switches the interface between English and Nederlands. **System** follows the language of your computer. The same choice is in File > Settings. The help follows the interface language.

## The document language

Each map has its own language, English or Dutch, set on the File > **Document** page. It is used for:

- the checks that look at words: "and"/"or" ("en"/"of" in Dutch) and the key words, which skip the common words of that language. See [Checks](checks);
- spellcheck;
- the linking words and source names in the outline and essay exports.

File > Settings > **Language of new documents** sets the language a new map starts with. With **Same as interface** (the default) a new map takes the language of the interface.

## Spelling

Misspelled words get a red underline while you type in a box, an essay paragraph, a snippet or a comment. The dictionaries for English and Dutch come with ReasonCraft, so this works offline. Underlines never show on the map or in exports.

- **F7** (or Home > **Spelling**) goes through the misspellings in box text, sources and notes, one at a time, from the selection.
- For each word you can pick a suggestion and use **Change** or **Change all**, skip it with **Ignore** or **Ignore all**, or **Add to dictionary**.
- The personal dictionary is kept in your settings and counts for every language.
- File > Settings turns spellcheck off.

## Theme and size

View > Theme picks System, Light or Dark; the button in the status bar switches between light and dark. File > Settings > **Interface size** makes the whole interface larger or smaller (80 % to 200 %), apart from the zoom of the map.
